# cmd

## Visão Geral
Binários executáveis e pontos de entrada da aplicação *The Legend of the Go Dragon*, fornecendo tanto execução local via terminal quanto hospedagem de servidor remoto multi-usuário via SSH.

## Subdiretórios e Fronteiras
- [cmd/lotgd](./lotgd/README.md) — Ponto de entrada do cliente de terminal local standalone.
- [cmd/server](./server/README.md) — Ponto de entrada do servidor SSH multi-usuário (Wish).
